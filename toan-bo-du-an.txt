# Hướng dẫn cho agent — QuanLyKhachSan

## Phạm vi và cấu trúc

Mã nguồn Java hiện nằm trong thư mục `scr/` (tên thư mục này được giữ nguyên; không tự đổi thành `src/`). `MAINNE.java` ở ngay trong `scr/` và không khai báo package.

- `scr/MAINNE.java`: điểm vào `main`, khởi chạy `ui.HeThongUI`, gọi đăng nhập rồi rẽ nhánh theo vai trò. Vai trò đang gán cứng `ADMIN`; nhánh nhân viên hiện chỉ là phần khung/comment.
- `scr/DAO/`: lớp truy cập dữ liệu cho khách hàng, đặt phòng, dịch vụ, chi tiết dịch vụ, hóa đơn, thanh toán, phòng, tài khoản và nhân viên. Hầu hết DAO thao tác trên bộ nhớ; các DAO dạng mảng có sức chứa cố định 100 phần tử, biến danh sách/số lượng `static`, cung cấp các thao tác CRUD và tìm kiếm. Một số lớp dùng `ArrayList`. Chưa có persistence thực sự.
- `scr/Database/`: hiện chỉ có `.gitkeep`, chưa có lớp kết nối, schema hay cấu hình cơ sở dữ liệu.
- `scr/INTERFACE/`: `IPhong` và `IThanhToan` là file rỗng hiện tại; tuy nhiên `QLPhong`/`PhongUI` đang import và sử dụng `INTERFACE.IPhong`, vì vậy cần đối chiếu trạng thái build thực tế trước khi sửa các phụ thuộc này.
- `scr/model/`: mô hình nghiệp vụ và trạng thái. Gồm khách hàng, nhân viên, tài khoản, phòng (lớp cơ sở cùng `PhongThuong`/`PhongVIP`), đặt phòng, dịch vụ, chi tiết dịch vụ, hóa đơn, thanh toán, thống kê và các enum trạng thái. Có tính toán tiền/kiểm tra ngày ở một số mô hình; dùng `LocalDate`, `BigDecimal` và các kiểu Java chuẩn.
- `scr/service/`: nghiệp vụ quản lý đặt phòng, dịch vụ, khách hàng, phòng và thanh toán. Các lớp service gọi DAO, kiểm tra đầu vào/quy tắc nghiệp vụ, phối hợp nhiều thực thể khi đặt phòng hoặc thanh toán.
- `scr/ui/`: giao diện console dùng `Scanner`/`System.out`. `PhongUI` cung cấp menu CRUD/thống kê phòng thông qua `QLPhong`; `HeThongUI` có đăng nhập/menu quản trị nhưng một số nghiệp vụ còn mô phỏng hoặc đang phát triển.
- `scr/util/`: hiện có `CheckVariable`, `DateTime`, `FormatHelper`, `InputHelper` nhưng đều là khung rỗng.

Có thư mục `scRr/test/java/README.md` riêng (khác cách viết hoa/thường với `scr`); không xem đây là package nguồn chính nếu chưa xác minh cấu hình build.

## Kiến trúc và luồng phụ thuộc

Định hướng tổng thể là phân lớp kiểu console MVC/service/DAO: `MAINNE` → `ui` → `service` → `DAO` → `model`. Mô hình chứa dữ liệu và một phần hành vi nghiệp vụ; DAO hiện là kho dữ liệu trong bộ nhớ; service thực hiện xác thực và điều phối; UI xử lý nhập/xuất. Duy trì chiều phụ thuộc này khi bổ sung chức năng, tránh để model phụ thuộc UI/DAO. Tuy nhiên mã hiện chưa đồng nhất hoàn toàn: `QLDichVu` import package chữ thường `dao.*`, trong khi các DAO trong `scr/DAO` khai báo `package DAO`; một vài lớp DAO/model thiếu khai báo package; `PhongDAO` trong workspace hiện là bộ khung với chữ ký `void`, không khớp API mà `QLPhong` gọi. Không giả định dự án đang biên dịch được hoặc tự ý sửa hàng loạt các bất nhất này khi chỉ làm tài liệu.

## Công nghệ và trạng thái triển khai

- Java, giao diện dòng lệnh; không thấy cấu hình Maven/Gradle hay framework trong cấu trúc được quét.
- Thư viện chuẩn Java được dùng gồm `java.util` (`Scanner`, `List`, `ArrayList`), `java.time` (`LocalDate`, `ChronoUnit`) và `java.math.BigDecimal`.
- Lưu trữ hiện tại chủ yếu là mảng/`ArrayList` trong tiến trình; dữ liệu không được lưu bền qua lần chạy. Không có kết nối JDBC/cơ sở dữ liệu được triển khai trong `Database`.
- Một số luồng còn là demo/placeholder: đăng nhập trong `HeThongUI` luôn thành công theo logic giả lập; vai trò trong `MAINNE` bị gán cứng; menu nhân viên/tài khoản/thống kê chưa nối đầy đủ; util và interface đang rỗng.
- Mã nguồn hiện có dấu hiệu không đồng nhất encoding tiếng Việt ở comment/thông báo. Giữ UTF-8 khi đọc/ghi file và không tự đổi encoding nếu không nằm trong phạm vi yêu cầu.

## Quy tắc khi chỉnh sửa

1. Đọc các lớp liên quan và giữ đúng tên package, kiểu dữ liệu, chữ ký phương thức hiện có; lưu ý Java phân biệt hoa/thường trong package và đường dẫn.
2. Giữ phân lớp UI → service → DAO → model. UI chỉ lo nhập/xuất và gọi service; đặt kiểm tra nghiệp vụ trong service/model; DAO lo truy xuất/lưu trữ.
3. Với DAO CRUD, giữ quy ước trả `boolean` cho thao tác thành công/thất bại, trả `null` khi không tìm thấy đối tượng và trả danh sách/array không chứa ô trống. Tôn trọng giới hạn mảng hiện có hoặc làm rõ mọi thay đổi về cấu trúc lưu trữ.
4. Kiểm tra `null`, chuỗi rỗng, mã trùng và dữ liệu số/ngày hợp lệ theo quy tắc của miền nghiệp vụ. Trạng thái nên dùng enum sẵn có thay vì thêm chuỗi tùy ý khi phù hợp.
5. Dùng `BigDecimal` cho tiền phòng/giá trị tiền được mô hình hóa bằng `BigDecimal`; tránh chuyển qua `double` nếu không cần thiết. Ngày nghiệp vụ dùng `LocalDate`.
6. Dùng tên tiếng Việt không dấu theo phong cách hiện hữu cho định danh và tên miền; tên lớp/enum viết PascalCase, phương thức/biến camelCase. Giữ thay đổi gọn trong phạm vi nhiệm vụ.
7. Không coi class rỗng, comment mô tả dự định, hoặc menu giả lập là chức năng đã hoàn tất. Nêu rõ phần nào là triển khai thực tế và phần nào là placeholder khi tài liệu hóa hoặc mở rộng.
8. Trước khi thêm phụ thuộc/thư viện hoặc tích hợp database, kiểm tra cấu hình dự án (hiện chưa thấy Maven/Gradle); không khẳng định công nghệ chưa được khai báo là đang sử dụng.

Khi được yêu cầu kiểm chứng code, trước tiên xác định cách build/chạy khả dụng từ repository. Do package/API đang có bất nhất, ghi nhận chính xác lỗi nền nếu build không thành công và phân biệt với lỗi do thay đổi mới. Không tự sửa các vấn đề ngoài phạm vi chỉ để làm cho build xanh.

## Phân công module của người dùng

Khi làm việc trên các phần liên quan, lưu ý phạm vi phụ trách của người dùng:

- **Model:** chi tiết dịch vụ, dịch vụ, hóa đơn, thanh toán và trạng thái thanh toán.
- **DAO:** dịch vụ, hóa đơn và thanh toán.
- **Service:** `QLDichVu` và `QThanhToan`.
- **Interface:** `IThanhToan`.
- **UI:** chưa làm.

Ưu tiên giữ các lớp thuộc phạm vi này nhất quán với nhau; không giả định UI của các chức năng này đã được triển khai.

package DAO;

import java.io.*;
import java.math.BigDecimal;
import java.time.LocalDate;
import java.util.*;
import model.ChiTietDichVu;

public class ChiTietDichVuDAO {
    private static final String FILE_PATH = "DATABASEH/ChiTietDichVu.dat";
    public static ChiTietDichVu[] danhSachChiTiet = new ChiTietDichVu[100];
    public static int soLuongChiTiet = 0;
    static {
        docFile();
    }

    private static void ghiChuoi(DataOutputStream dos, String s) throws IOException {
        dos.writeUTF(s == null ? "" : s);
    }

    private static String docChuoi(DataInputStream dis) throws IOException {
        String s = dis.readUTF();
        return s.isEmpty() ? null : s;
    }

    private static void ghiNgay(DataOutputStream dos, LocalDate d) throws IOException {
        dos.writeLong(d == null ? -1L : d.toEpochDay());
    }

    private static LocalDate docNgay(DataInputStream dis) throws IOException {
        long v = dis.readLong();
        return v == -1L ? null : LocalDate.ofEpochDay(v);
    }

    private static void docFile() {
        soLuongChiTiet = 0;
        Arrays.fill(danhSachChiTiet, null);
        File f = new File(FILE_PATH);
        try {
            if (!f.exists() || f.length() == 0)
                return;
            try (DataInputStream dis = new DataInputStream(new BufferedInputStream(new FileInputStream(f)))) {
                int count = dis.readInt();
                if (count < 0 || count > 100)
                    throw new IOException("So luong khong hop le");
                for (int i = 0; i < count; i++) {
                    ChiTietDichVu c = new ChiTietDichVu(docChuoi(dis), docChuoi(dis), docNgay(dis), docNgay(dis),
                            dis.readInt(), new BigDecimal(dis.readUTF()));
                    BigDecimal total = new BigDecimal(dis.readUTF());
                    if (hopLe(c) && timNoiBo(c.getMaDatPhong(), c.getMaDichVu()) == null) {
                        c.setThanhTien(total);
                        danhSachChiTiet[soLuongChiTiet++] = c;
                    }
                }
            }
        } catch (Exception e) {
            System.err.println("Khong doc duoc " + FILE_PATH + ": " + e.getMessage());
        }
    }

    private static ChiTietDichVu timNoiBo(String dp, String dv) {
        for (int i = 0; i < soLuongChiTiet; i++)
            if (cungKhoa(danhSachChiTiet[i], dp, dv))
                return danhSachChiTiet[i];
        return null;
    }

    private static boolean ghiFile() {
        File f = new File(FILE_PATH);
        if (!f.exists()) {
            System.err.println("Khong tim thay file: " + FILE_PATH);
            return false;
        }
        try {
            try (DataOutputStream dos = new DataOutputStream(new BufferedOutputStream(new FileOutputStream(f)))) {
                dos.writeInt(soLuongChiTiet);
                for (int i = 0; i < soLuongChiTiet; i++) {
                    ChiTietDichVu c = danhSachChiTiet[i];
                    ghiChuoi(dos, c.getMaDatPhong());
                    ghiChuoi(dos, c.getMaDichVu());
                    ghiNgay(dos, c.getNgayDatDichVu());
                    ghiNgay(dos, c.getNgayNhan());
                    dos.writeInt(c.getSoLuong());
                    dos.writeUTF(c.getDonGia().toString());
                    dos.writeUTF(tinhThanhTienNoiBo(c).toString());
                }
            }
            return true;
        } catch (Exception e) {
            System.err.println("Khong ghi duoc " + FILE_PATH + ": " + e.getMessage());
            return false;
        }
    }

    public boolean them(ChiTietDichVu c) {
        if (!hopLe(c))
            return false;
        ChiTietDichVu cu = timTheoMa(c.getMaDatPhong(), c.getMaDichVu());
        if (cu != null) {
            int sl = cu.getSoLuong();
            BigDecimal dg = cu.getDonGia(), tt = cu.getThanhTien();
            cu.setSoLuong(sl + c.getSoLuong());
            cu.setDonGia(c.getDonGia());
            cu.setThanhTien(tinhThanhTien(cu));
            if (!ghiFile()) {
                cu.setSoLuong(sl);
                cu.setDonGia(dg);
                cu.setThanhTien(tt);
                return false;
            }
            return true;
        }
        if (soLuongChiTiet >= 100)
            return false;
        c.setThanhTien(tinhThanhTien(c));
        int old = soLuongChiTiet;
        danhSachChiTiet[soLuongChiTiet++] = c;
        if (!ghiFile()) {
            soLuongChiTiet = old;
            danhSachChiTiet[old] = null;
            return false;
        }
        return true;
    }

    public boolean sua(ChiTietDichVu c) {
        if (!hopLe(c))
            return false;
        for (int i = 0; i < soLuongChiTiet; i++)
            if (cungKhoa(danhSachChiTiet[i], c.getMaDatPhong(), c.getMaDichVu())) {
                ChiTietDichVu old = danhSachChiTiet[i];
                BigDecimal tt = c.getThanhTien();
                c.setThanhTien(tinhThanhTien(c));
                danhSachChiTiet[i] = c;
                if (!ghiFile()) {
                    danhSachChiTiet[i] = old;
                    c.setThanhTien(tt);
                    return false;
                }
                return true;
            }
        return false;
    }

    public BigDecimal tinhThanhTien(ChiTietDichVu c) {
        return tinhThanhTienNoiBo(c);
    }

    public boolean xoa(String dp, String dv) {
        for (int i = 0; i < soLuongChiTiet; i++)
            if (cungKhoa(danhSachChiTiet[i], dp, dv)) {
                ChiTietDichVu[] old = Arrays.copyOf(danhSachChiTiet, soLuongChiTiet);
                int n = soLuongChiTiet;
                System.arraycopy(danhSachChiTiet, i + 1, danhSachChiTiet, i, --soLuongChiTiet - i);
                danhSachChiTiet[soLuongChiTiet] = null;
                if (!ghiFile()) {
                    System.arraycopy(old, 0, danhSachChiTiet, 0, n);
                    soLuongChiTiet = n;
                    return false;
                }
                return true;
            }
        return false;
    }

    public ChiTietDichVu timTheoMa(String dp, String dv) {
        return timNoiBo(dp, dv);
    }

    public ChiTietDichVu[] layDanhSach() {
        return Arrays.copyOf(danhSachChiTiet, soLuongChiTiet);
    }

    public ChiTietDichVu[] layTheoMaDatPhong(String dp) {
        ArrayList<ChiTietDichVu> a = new ArrayList<>();
        for (int i = 0; i < soLuongChiTiet; i++)
            if (danhSachChiTiet[i] != null && dp != null && dp.equals(danhSachChiTiet[i].getMaDatPhong()))
                a.add(danhSachChiTiet[i]);
        return a.toArray(new ChiTietDichVu[0]);
    }

    public boolean kiemTraDichVuDangSuDung(String ma) {
        for (int i = 0; i < soLuongChiTiet; i++)
            if (danhSachChiTiet[i] != null && ma != null && ma.equals(danhSachChiTiet[i].getMaDichVu()))
                return true;
        return false;
    }

    public BigDecimal tinhTongTienTheoDatPhong(String dp) {
        BigDecimal sum = BigDecimal.ZERO;
        for (ChiTietDichVu c : layTheoMaDatPhong(dp))
            sum = sum.add(tinhThanhTien(c));
        return sum;
    }

    private static BigDecimal tinhThanhTienNoiBo(ChiTietDichVu c) {
        return c == null || c.getDonGia() == null ? BigDecimal.ZERO
                : c.getDonGia().multiply(BigDecimal.valueOf(c.getSoLuong()));
    }

    private static boolean hopLe(ChiTietDichVu c) {
        return c != null && !rong(c.getMaDatPhong()) && !rong(c.getMaDichVu()) && c.getSoLuong() > 0
                && c.getDonGia() != null && c.getDonGia().signum() >= 0;
    }

    private static boolean cungKhoa(ChiTietDichVu c, String dp, String dv) {
        return c != null && dp != null && dv != null && dp.equals(c.getMaDatPhong()) && dv.equals(c.getMaDichVu());
    }

    private static boolean rong(String s) {
        return s == null || s.trim().isEmpty();
    }
}

package DAO;

import model.DatPhong;
import model.TrangThaiDatPhong;
import java.time.LocalDate;


public class DatPhongDAO {
    public static DatPhong[] danhSachDatPhong = new DatPhong[100];
    public static int soLuongDatPhong = 0;

    public boolean them(DatPhong datPhong) {
        if (datPhong == null || datPhong.getMaDatPhong() == null 
            || timTheoMa(datPhong.getMaDatPhong()) != null 
            || soLuongDatPhong == danhSachDatPhong.length) {
            return false;
        }
        danhSachDatPhong[soLuongDatPhong] = datPhong;
        soLuongDatPhong++;
        return true;
    }

    public boolean sua(DatPhong datPhong) {
        if (datPhong == null) return false;
        for (int i = 0; i < soLuongDatPhong; i++) {
            if (danhSachDatPhong[i].getMaDatPhong().equals(datPhong.getMaDatPhong())) {
                danhSachDatPhong[i] = datPhong;
                return true;
            }
        }
        return false;
    }

    public boolean xoa(String maDatPhong) {
        for (int i = 0; i < soLuongDatPhong; i++) {
            if (danhSachDatPhong[i].getMaDatPhong().equals(maDatPhong)) {
                System.arraycopy(danhSachDatPhong, i + 1, danhSachDatPhong, i, soLuongDatPhong - i - 1);
                danhSachDatPhong[--soLuongDatPhong] = null;
                return true;
            }
        }
        return false;
    }

    public DatPhong timTheoMa(String maDatPhong) {
        for (int i = 0; i < soLuongDatPhong; i++) {
            if (danhSachDatPhong[i].getMaDatPhong().equals(maDatPhong)) {
                return danhSachDatPhong[i];
            }
        }
        return null;
    }

    /** Kiểm tra xem phòng có trống trong khoảng thời gian dự định đặt hay không */
    public boolean kiemTraPhongTrong(String maPhong, LocalDate ngayNhan, LocalDate ngayTra) {
        for (int i = 0; i < soLuongDatPhong; i++) {
            DatPhong dp = danhSachDatPhong[i];
            // Chỉ kiểm tra các phòng trùng mã và phiếu đặt chưa bị hủy hoặc trả phòng
            if (dp.getMaPhong().equalsIgnoreCase(maPhong) &&
                dp.getTrangThai() != TrangThaiDatPhong.DA_HUY &&
                dp.getTrangThai() != TrangThaiDatPhong.DA_TRA) {
                
                // Nếu khoảng thời gian bị chồng lấp -> Phòng không trống
                if (dp.isTrungLich(ngayNhan, ngayTra)) {
                    return false;
                }
            }
        }
        return true;
    }

    public DatPhong[] layDanhSach() {
        DatPhong[] ketQua = new DatPhong[soLuongDatPhong];
        System.arraycopy(danhSachDatPhong, 0, ketQua, 0, soLuongDatPhong);
        return ketQua;
    }
}

            return false;
        }

        if (nv.getHoTen() == null || nv.getHoTen().trim().isEmpty()) {
            return false;

            return false;
        }

            moRongMang();
        }

        danhSach[soLuong] = nv;

            return false;
        }

        if (nv.getMaNV() == null || nv.getMaNV().trim().isEmpty()) {
            return false;
        }

            return false;
        }

        for (int i = 0; i < soLuong; i++) {
            NhanVien nhanVienCu = danhSach[i];

            if (nhanVienCu != null && nhanVienCu.getMaNV() != null
                    && nhanVienCu.getMaNV().equalsIgnoreCase(ma)) {
                danhSach[i] = nv;
                return true;
            }
        }

        return false;
    }

        if (maNV == null || maNV.trim().isEmpty()) {
            return false;
        }

        String maCanXoa = maNV.trim();

        for (int i = 0; i < soLuong; i++) {
            if (danhSach[i] != null && danhSach[i].getMaNV() != null
                    && danhSach[i].getMaNV().equalsIgnoreCase(maCanXoa)) {

                for (int j = i; j < soLuong - 1; j++) {
                    danhSach[j] = danhSach[j + 1];
                }

    private static final String FILE_PATH =
            DatabaseManager.getDuongDanFile("phong.dat");

    private static final int MAX_PHONG = 100;

    private static Phong[] danhSachPhong = new Phong[MAX_PHONG];

    private static int soLuongPhong = 0;

    // Đọc dữ liệu từ file khi lớp được khởi tạo
    static {
        docFile();
    }

    // =========================
    // GHI FILE
    // =========================

    private static boolean ghiFile() {

        File file = new File(FILE_PATH);
        File folder = file.getParentFile();

        // Tạo thư mục nếu chưa tồn tại
        if (folder != null && !folder.exists()) {
            folder.mkdirs();
        }

        try (DataOutputStream outStream =
                     new DataOutputStream(
                             new FileOutputStream(FILE_PATH))) {

            for (int i = 0; i < soLuongPhong; i++) {

                Phong p = danhSachPhong[i];

                if (p instanceof PhongThuong) {

                    outStream.writeUTF("THUONG");

                } else if (p instanceof PhongVIP) {

                    outStream.writeUTF("VIP");

                } else {

                    throw new IOException("Loai phong khong hop le!");
                }

                // Ghi thông tin chung của phòng
                outStream.writeUTF(p.getMaPhong());
                outStream.writeUTF(p.getTenPhong());
                outStream.writeUTF(p.getLoaiPhong());
                outStream.writeUTF(p.getGiaPhong().toPlainString());
                outStream.writeUTF(p.getTinhTrang().name());

                // Ghi thông tin riêng của từng lớp con
                if (p instanceof PhongThuong) {

                    PhongThuong pt = (PhongThuong) p;

                    outStream.writeUTF(pt.getDichVuThuong());

                } else if (p instanceof PhongVIP) {

                    PhongVIP pv = (PhongVIP) p;

                    outStream.writeUTF(pv.getDichVuVIP());
                }
            }

            return true;

        } catch (IOException e) {

            System.out.println("Loi khi ghi file phong: " + e.getMessage());

            return false;
        }
    }

    // =========================
    // ĐỌC FILE
    // =========================

    private static void docFile() {

        File file = new File(FILE_PATH);

        // Nếu file chưa tồn tại thì chưa có dữ liệu để đọc
        if (!file.exists()) {
            return;
        }

        Phong[] dsTam = new Phong[MAX_PHONG];
        int dem = 0;

        try (DataInputStream inStream =
                     new DataInputStream(
                             new FileInputStream(FILE_PATH))) {

            while (inStream.available() > 0) {

                if (dem >= MAX_PHONG) {
                    System.out.println("Danh sach phong da day!");
                    break;
                }

                // Đọc loại phòng
                String loai = inStream.readUTF();

                // Đọc thông tin chung
                String maPhong = inStream.readUTF();
                String tenPhong = inStream.readUTF();
                String loaiPhong = inStream.readUTF();

                BigDecimal giaPhong =
                        new BigDecimal(inStream.readUTF());

                TinhTrangPhong tinhTrang =
                        TinhTrangPhong.valueOf(inStream.readUTF());

                // Đọc thông tin riêng và tạo đối tượng
                if (loai.equals("THUONG")) {

                    String dichVuThuong = inStream.readUTF();

                    dsTam[dem] = new PhongThuong(
                            maPhong,
                            tenPhong,
                            loaiPhong,
                            giaPhong,
                            tinhTrang,
                            dichVuThuong
                    );

                } else if (loai.equals("VIP")) {

                    String dichVuVIP = inStream.readUTF();

                    dsTam[dem] = new PhongVIP(
                            maPhong,
                            tenPhong,
                            loaiPhong,
                            giaPhong,
                            tinhTrang,
                            dichVuVIP
                    );

                } else {

                    throw new IOException("Loai phong trong file khong hop le!");
                }

                dem++;
            }

            // Chỉ cập nhật danh sách sau khi đọc thành công
            danhSachPhong = dsTam;
            soLuongPhong = dem;

            System.out.println("Doc file phong thanh cong!");

        } catch (IOException | IllegalArgumentException e) {

            System.out.println("Loi khi doc file phong: " + e.getMessage());
        }
    }

    // =========================
    // THÊM PHÒNG
    // =========================

    public boolean themPhong(Phong phong) {

        if (phong == null) {
            System.out.println("Phong khong hop le!");
            return false;
        }

        if (soLuongPhong >= MAX_PHONG) {
            System.out.println("Danh sach phong da day!");
            return false;
        }

        if (timPhongTheoMa(phong.getMaPhong()) != null) {
            System.out.println("Ma phong da ton tai!");
            return false;
        }

        danhSachPhong[soLuongPhong] = phong;
        soLuongPhong++;

        // Nếu ghi file thất bại thì khôi phục mảng
        if (!ghiFile()) {
            soLuongPhong--;
            danhSachPhong[soLuongPhong] = null;
            return false;
        }

        return true;
    }

    // XÓA PHÒNG
    // =========================

    public boolean xoaPhong(String maPhong) {

        int viTri = -1;

        for (int i = 0; i < soLuongPhong; i++) {

            if (danhSachPhong[i].getMaPhong().equalsIgnoreCase(maPhong)) {
                viTri = i;
                break;
            }
        }

        if (viTri == -1) {
            System.out.println("Khong tim thay phong!");
            return false;
        }

        // Sao lưu danh sách để khôi phục nếu ghi file thất bại
        Phong[] backup = danhSachPhong.clone();
        int soLuongCu = soLuongPhong;

        // Dồn các phần tử phía sau lên trước
        for (int i = viTri; i < soLuongPhong - 1; i++) {
            danhSachPhong[i] = danhSachPhong[i + 1];
        }

        soLuongPhong--;
        danhSachPhong[soLuongPhong] = null;

        if (!ghiFile()) {

            danhSachPhong = backup;
            soLuongPhong = soLuongCu;

            return false;
        }

        return true;
    }

            return false;

        Phong phongTrung = timPhongTheoMa(phongMoi.getMaPhong());

            return false;

        }

        if (tk == null) {
            return false;
        }

import java.time.LocalDate;

import model.ThanhToan;

public class ThanhToanDAO {
    private static final String FILE_PATH = "DATABASEH/ThanhToan.dat";
    public static ThanhToan[] danhSachThanhToan = new ThanhToan[100];
    public static int soLuongThanhToan = 0;
    static {
        docFile();
    }

    private static void ghiChuoi(DataOutputStream dos, String s) throws IOException {
        dos.writeUTF(s == null ? "" : s);
    }

    private static String docChuoi(DataInputStream dis) throws IOException {
        String s = dis.readUTF();
        return s.isEmpty() ? null : s;
    }

    private static void ghiNgay(DataOutputStream dos, LocalDate d) throws IOException {
        dos.writeLong(d == null ? -1L : d.toEpochDay());
    }

    private static LocalDate docNgay(DataInputStream dis) throws IOException {
        long v = dis.readLong();
        return v == -1L ? null : LocalDate.ofEpochDay(v);
    }

    private static void docFile() {
        soLuongThanhToan = 0;
        Arrays.fill(danhSachThanhToan, null);
        File f = new File(FILE_PATH);
        try {
            if (!f.exists() || f.length() == 0)
                return;
            try (DataInputStream dis = new DataInputStream(new BufferedInputStream(new FileInputStream(f)))) {
                int count = dis.readInt();
                if (count < 0 || count > 100)
                    throw new IOException("So luong khong hop le");
                for (int i = 0; i < count; i++) {
                    String t = docChuoi(dis);
                    ThanhToan tToan = new ThanhToan(docChuoi(dis), docChuoi(dis), new BigDecimal(dis.readUTF()),
                            docChuoi(dis), docNgay(dis), t == null ? null : TrangThaiThanhToan.valueOf(t));
                    if (hopLe(tToan) && timNoiBo(tToan.getMaThanhToan()) == null)
                        danhSachThanhToan[soLuongThanhToan++] = tToan;
                }
            }
        } catch (Exception e) {
            System.err.println("Khong doc duoc " + FILE_PATH + ": " + e.getMessage());
        }
    }

    private static ThanhToan timNoiBo(String ma) {
        for (int i = 0; i < soLuongThanhToan; i++)
            if (ma.equals(danhSachThanhToan[i].getMaThanhToan()))
                return danhSachThanhToan[i];
        return null;
    }

    private static boolean ghiFile() {
        File f = new File(FILE_PATH);
        if (!f.exists()) {
            System.err.println("Khong tim thay file: " + FILE_PATH);
            return false;
        }
        try {
            try (DataOutputStream dos = new DataOutputStream(new BufferedOutputStream(new FileOutputStream(f)))) {
                dos.writeInt(soLuongThanhToan);
                for (int i = 0; i < soLuongThanhToan; i++) {
                    ThanhToan t = danhSachThanhToan[i];
                    ghiChuoi(dos, t.getMaThanhToan());
                    ghiChuoi(dos, t.getMaHD());
                    dos.writeUTF(t.getSoTien().toString());
                    ghiChuoi(dos, t.getPhuongThuc());
                    ghiNgay(dos, t.getNgayThanhToan());
                    ghiChuoi(dos, t.getTrangThai() == null ? null : t.getTrangThai().name());
                }
            }
            return true;
        } catch (Exception e) {
            System.err.println("Khong ghi duoc " + FILE_PATH + ": " + e.getMessage());
            return false;
        }
    }

    public boolean them(ThanhToan t) {
        if (!hopLe(t) || timTheoMa(t.getMaThanhToan()) != null || soLuongThanhToan >= 100)
            return false;
        int old = soLuongThanhToan;
        danhSachThanhToan[soLuongThanhToan++] = t;
        if (!ghiFile()) {
            soLuongThanhToan = old;
            danhSachThanhToan[old] = null;
            return false;
        }
        return true;
    }

    public boolean sua(ThanhToan t) {
        if (!hopLe(t))
            return false;
        for (int i = 0; i < soLuongThanhToan; i++)
            if (danhSachThanhToan[i] != null && t.getMaThanhToan().equals(danhSachThanhToan[i].getMaThanhToan())) {
                ThanhToan old = danhSachThanhToan[i];
                danhSachThanhToan[i] = t;
                if (!ghiFile()) {
                    danhSachThanhToan[i] = old;
                    return false;
                }
                return true;
            }
        return false;
    }

    public boolean xoa(String ma) {
        for (int i = 0; i < soLuongThanhToan; i++)
            if (danhSachThanhToan[i] != null && ma != null && ma.equals(danhSachThanhToan[i].getMaThanhToan())) {
                ThanhToan[] old = Arrays.copyOf(danhSachThanhToan, soLuongThanhToan);
                int n = soLuongThanhToan;
                System.arraycopy(danhSachThanhToan, i + 1, danhSachThanhToan, i, --soLuongThanhToan - i);
                danhSachThanhToan[soLuongThanhToan] = null;
                if (!ghiFile()) {
                    System.arraycopy(old, 0, danhSachThanhToan, 0, n);
                    soLuongThanhToan = n;
                    return false;
                }
                return true;
            }
        return false;
    }

    public ThanhToan timTheoMa(String ma) {
        if (rong(ma))
            return null;
        for (int i = 0; i < soLuongThanhToan; i++)
            if (danhSachThanhToan[i] != null && ma.equals(danhSachThanhToan[i].getMaThanhToan()))
                return danhSachThanhToan[i];
        return null;
    }

    public ThanhToan[] layTheoMaHD(String ma) {

        for (int i = 0; i < soLuongThanhToan; i++)
            if (danhSachThanhToan[i] != null && ma != null && ma.equals(danhSachThanhToan[i].getMaHD()))
                a.add(danhSachThanhToan[i]);
        return a.toArray(new ThanhToan[0]);
    }

        return Arrays.copyOf(danhSachThanhToan, soLuongThanhToan);

package model;
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.Objects;

public class DatPhong {
    private String maDatPhong;
    private String maKhachHang;
    private String maPhong;
    private LocalDate ngayDat;
    private LocalDate ngayNhanPhong;
    private LocalDate ngayTraPhong;
    private TrangThaiDatPhong trangThai;
    private double giaPhongNgay;

    public DatPhong() {
        this.ngayDat = LocalDate.now();
        this.trangThai = TrangThaiDatPhong.DA_DAT;
    }

    public DatPhong(String maDatPhong, String maKhachHang, String maPhong, 
                    LocalDate ngayNhanPhong, LocalDate ngayTraPhong, double giaPhongNgay) {
        this.maDatPhong = maDatPhong;
        this.maKhachHang = maKhachHang;
        this.maPhong = maPhong;
        this.ngayDat = LocalDate.now();
        this.ngayNhanPhong = ngayNhanPhong;
        this.ngayTraPhong = ngayTraPhong;
        this.giaPhongNgay = giaPhongNgay;
        this.trangThai = TrangThaiDatPhong.DA_DAT;
    }


    public String getMaDatPhong() { return maDatPhong; }
    public void setMaDatPhong(String maDatPhong) { this.maDatPhong = maDatPhong; }

    public String getMaKhachHang() { return maKhachHang; }
    public void setMaKhachHang(String maKhachHang) { this.maKhachHang = maKhachHang; }

    public String getMaPhong() { return maPhong; }
    public void setMaPhong(String maPhong) { this.maPhong = maPhong; }

    public LocalDate getNgayDat() { return ngayDat; }
    public void setNgayDat(LocalDate ngayDat) { this.ngayDat = ngayDat; }

    public LocalDate getNgayNhanPhong() { return ngayNhanPhong; }
    public void setNgayNhanPhong(LocalDate ngayNhanPhong) { this.ngayNhanPhong = ngayNhanPhong; }

    public LocalDate getNgayTraPhong() { return ngayTraPhong; }
    public void setNgayTraPhong(LocalDate ngayTraPhong) { this.ngayTraPhong = ngayTraPhong; }

    public TrangThaiDatPhong getTrangThai() { return trangThai; }
    public void setTrangThai(TrangThaiDatPhong trangThai) { this.trangThai = trangThai; }

    public double getGiaPhongNgay() { return giaPhongNgay; }
    public void setGiaPhongNgay(double giaPhongNgay) { this.giaPhongNgay = giaPhongNgay; }



    public long getSoNgayO() {
        if (ngayNhanPhong == null || ngayTraPhong == null) return 0;
        long soNgay = ChronoUnit.DAYS.between(ngayNhanPhong, ngayTraPhong);
        return soNgay > 0 ? soNgay : 1; 
    }

    public double tinhTienPhong() {
        return getSoNgayO() * giaPhongNgay;
    }

    public boolean isNgayHopLe() {
        if (ngayNhanPhong == null || ngayTraPhong == null) return false;
        return !ngayTraPhong.isBefore(ngayNhanPhong);
    }

        if (this.trangThai == TrangThaiDatPhong.DA_HUY || this.trangThai == TrangThaiDatPhong.DA_TRA) {

        }
        return this.ngayNhanPhong.isBefore(denNgay) && this.ngayTraPhong.isAfter(tuNgay);
    }

public class QLDatPhong {
    private DatPhongDAO datPhongDAO = new DatPhongDAO();

    public boolean taoDatPhong(DatPhong dp) {
        if (dp == null || !dp.isNgayHopLe()) {
            System.out.println("Lỗi: Ngày nhận hoặc ngày trả phòng không hợp lệ!");
            return false;
        }
        // Kiểm tra phòng có trống trong lịch đặt không
        if (!datPhongDAO.kiemTraPhongTrong(dp.getMaPhong(), dp.getNgayNhanPhong(), dp.getNgayTraPhong())) {
            System.out.println("Lỗi: Phòng " + dp.getMaPhong() + " đã có người đặt trong thời gian này!");
            return false;
        }

        boolean kq = datPhongDAO.them(dp);
        if (kq) System.out.println("Đặt phòng thành công! Tổng tiền dự kiến: " + dp.tinhTienPhong());
        else System.out.println("Đặt phòng thất bại (Trùng mã phiếu hoặc đầy danh sách)!");
        return kq;
    }

    public boolean huyDatPhong(String maDatPhong) {
        DatPhong dp = datPhongDAO.timTheoMa(maDatPhong);
        if (dp == null) {
            System.out.println("Không tìm thấy mã đặt phòng!");
            return false;
        }
        dp.setTrangThai(TrangThaiDatPhong.DA_HUY);
        System.out.println("Đã hủy đặt phòng thành công!");
        return true;
    }

    public DatPhong timDatPhong(String maDatPhong) {
        return datPhongDAO.timTheoMa(maDatPhong);
    }

        return datPhongDAO.layDanhSach();
    }

    // =========================

    private String chuanHoaMaPhong(String maPhong) {
        if (maPhong == null) {
            return null;
        }

        return maPhong.trim().toUpperCase();
    }

    // =========================
    // KIỂM TRA THÔNG TIN PHÒNG
    // =========================

    private boolean kiemTraThongTinPhong(Phong phong) {

        if (phong == null) {
            System.out.println("Thong tin phong khong hop le!");
            return false;
        }

        if (phong.getMaPhong() == null ||
            phong.getMaPhong().trim().isEmpty()) {

            System.out.println("Ma phong khong duoc de trong!");
            return false;
        }

        if (phong.getTenPhong() == null ||
            phong.getTenPhong().trim().isEmpty()) {

            System.out.println("Ten phong khong duoc de trong!");
            return false;
        }

        if (phong.getGiaPhong() == null ||
            phong.getGiaPhong().compareTo(BigDecimal.ZERO) <= 0) {

            System.out.println("Gia phong phai lon hon 0!");
            return false;
        }

        if (phong.getTinhTrang() == null) {
            System.out.println("Tinh trang phong khong hop le!");
            return false;
        }

        return true;
    }

    // =========================
    // THÊM PHÒNG
    // =========================

    @Override
    public boolean themPhong(Phong phong) {

        if (!kiemTraThongTinPhong(phong)) {
            return false;
        }

        // Chuẩn hóa mã phòng trước khi kiểm tra trùng
        String maPhong = chuanHoaMaPhong(phong.getMaPhong());

        // Gán mã đã chuẩn hóa vào đối tượng
        phong.setMaPhong(maPhong);

        // Kiểm tra mã phòng đã tồn tại chưa
        if (phongDAO.timPhongTheoMa(maPhong) != null) {
            System.out.println("Ma phong da ton tai!");
            return false;
        }

        return phongDAO.themPhong(phong);
    }

    // =========================
    // LẤY DANH SÁCH PHÒNG
    // =========================

    @Override
    public Phong[] layDanhSachPhong() {
        return phongDAO.layDanhSachPhong();
    }

    public Phong[] layDanhSachPhongTheoTinhTrang(
            TinhTrangPhong tinhTrang) {

            return new Phong[0];
        }

        return phongDAO.layDanhSachPhongTheoTinhTrang(tinhTrang);
    }

    // =========================
    // TÌM PHÒNG THEO MÃ
    // =========================

    @Override
    public Phong timPhongTheoMa(String maPhong) {

        maPhong = chuanHoaMaPhong(maPhong);

        if (maPhong == null || maPhong.isEmpty()) {
            System.out.println("Ma phong khong hop le!");
            return null;
        }

        return phongDAO.timPhongTheoMa(maPhong);
    }

    // SỬA PHÒNG
    // Không cho phép thay đổi mã phòng
    // =========================

    public boolean suaPhong(Phong phong) {

        if (!kiemTraThongTinPhong(phong)) {
            return false;
        }

        // Chuẩn hóa mã phòng
        String maPhong = chuanHoaMaPhong(phong.getMaPhong());

        // Tìm phòng cũ bằng mã phòng
        Phong phongCu = phongDAO.timPhongTheoMa(maPhong);

        if (phongCu == null) {
            System.out.println("Khong tim thay phong!");
            return false;

        phong.setMaPhong(phongCu.getMaPhong());

            return false;
        }

        return phongDAO.xoaPhong(maPhong);
    }

    private int nhapSoNguyen(String thongBao) {
        while (true) {
            try {
                System.out.print(thongBao);
                return Integer.parseInt(sc.nextLine().trim());
            } catch (NumberFormatException e) {
                System.out.println("Vui long nhap so nguyen!");
            }
        }
    }

    private int nhapSoDuong(String thongBao) {
        while (true) {
            int n = nhapSoNguyen(thongBao);
            if (n > 0) {
                return n;
            }
            System.out.println("Gia tri phai lon hon 0!");
        }
    }

    private int nhapLuaChon(String thongBao, int min, int max) {
        while (true) {
            int n = nhapSoNguyen(thongBao);
            if (n >= min && n <= max) {
                return n;
            }
            System.out.println("Lua chon khong hop le!");
        }
    }

    private BigDecimal nhapTien(String thongBao, boolean choPhepKhong) {
        while (true) {
            try {
                System.out.print(thongBao);
                BigDecimal tien = new BigDecimal(sc.nextLine().trim());
                if (choPhepKhong ? tien.signum() >= 0 : tien.signum() > 0) {
                    return tien;
                }
                System.out.println(choPhepKhong ? "Gia tri khong duoc am!" : "Gia tri phai lon hon 0!");
            } catch (NumberFormatException e) {
                System.out.println("So tien khong hop le!");
            }
        }
    }

    private String tien(BigDecimal giaTri) {
        return giaTri == null ? "0" : giaTri.toPlainString();
    }

    private String safe(Object giaTri) {
        return giaTri == null ? "" : giaTri.toString();
    }
